# Categorizador Automático de Productos en Python

## Descripción
Este proyecto implementa una herramienta en Python que permite categorizar automáticamente grandes volúmenes de datos mediante reglas basadas en palabras clave. Está diseñado para apoyar procesos de análisis de datos, control de inventarios y estandarización de información en entornos operativos.

El proyecto se presenta como un **caso académico con datos simulados**, sin utilizar información confidencial ni real.

## Funcionalidades
- Lectura de archivos Excel
- Clasificación automática de productos por categoría
- Uso de reglas de negocio personalizables
- Generación de archivo Excel con resultados categorizados
- Escalable para grandes volúmenes de datos

## Aplicaciones
- Análisis de ventas
- Gestión de inventarios
- Limpieza y normalización de bases de datos
- Soporte a la toma de decisiones operativas

## Requisitos
- Python 3.9 o superior
